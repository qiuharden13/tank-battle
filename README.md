# 🎮 坦克大战 (Tank Battle)

经典 FC 红白机坦克大战网页版，使用纯 HTML5 Canvas + JavaScript 实现，无需任何依赖。

## 🎯 游戏特色

- 🎨 **经典像素风格**地图和坦克设计
- 🧱 **可破坏砖墙**和不可破坏的钢铁墙
- 🦅 **基地保护** - 保护你的鹰标基地不被摧毁
- 🤖 **智能敌人 AI** - 敌人会随机移动并向你开火
- 📈 **3个预设关卡** + 无限随机关卡
- 💥 **粒子爆炸特效**
- 🛡️ **重生无敌时间**
- ⏸️ **暂停功能**
- 📊 **实时分数、生命、击杀统计**

## 🎮 操作方式

| 按键 | 功能 |
|------|------|
| `↑ ↓ ← →` 或 `W A S D` | 移动坦克 |
| `空格键` | 发射子弹 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |

## 🚀 快速开始

1. 克隆仓库：
```bash
git clone https://github.com/YOUR_USERNAME/tank-battle.git
```

2. 直接用浏览器打开 `index.html` 即可开始游戏！

或者直接访问 GitHub Pages 在线游玩。

## 🎨 游戏截图

游戏包含多种地图元素：
- 🧱 **棕色砖墙** - 可被子弹摧毁
- ⬜ **银色钢铁** - 无法摧毁
- 🦅 **金色鹰标** - 你的基地，被摧毁则游戏结束
- 🟢 **绿色坦克** - 玩家（有重生护盾）
- 🔴🟠🟣🟣 **彩色坦克** - 敌方坦克

## 🏆 计分规则

- 摧毁敌方坦克：+100 分
- 通关奖励：+500 × 关卡数 分

- CSS3 动画
